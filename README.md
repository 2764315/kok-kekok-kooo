# 発表配信ツール コッケコッコー!!!

自由研究などの発表系配信がスムーズに行えるように設計された、配信画面キャプチャー用のブラウザツールです。  
[GitHub Pages](https://2764315.github.io/kok-kekok-kooo/) を利用してブラウザ上ですぐに動作し、配信画面への取り込みや準備作業を効率化します。

---

## 機能
コッケコッコー!!!には、２つの機能があります。

| 用途 | 名称 | 説明 |
| --- | --- | --- |
| 準備用 | ファイル生成 | 発表の準備作業をサポートするモードです。|
| 配信用 | データプレビュー| 配信ソフトで画面キャプチャーして使用するためのモードです。 |

「設定」ボタンを押すと、各機能の細かな設定を変更することができます。

---

## 使い方

### 1. Googleフォームの回答をダウンロードする

### 2. ツールにアクセス
[発表配信ツール コッケコッコー!!!](https://2764315.github.io/kok-kekok-kooo/) にアクセスします。

### 3. CSVファイルの読み込みと操作
1. 「準備用」タブを開き、**[CSVを読み込む]** から対象のCSVファイルをアップロードします。
2. 読み込みが完了すると、左側メニューに操作ボタンが生成されます。
3. 項目を選択すると、画面上に **ファイル内容** および **生成ファイル構成** がプレビュー表示されます。
4. 設定が完了したら、**[ZIPをダウンロード]** ボタンを押し、ダウンロードします。
6. ZIPを解凍すると、下記のようなフォルダが展開されます。
 ```text
📁 ｺｯｹｺｯｺｰ!!!_(月月日日時時分分秒秒).zip  <-- ダウンロード用ZIP
│
├── 📁 00#-(研究タイトル)  <-- Googleフォームで送信された内容
│   │
│   ├── 📄 README-(研究タイトル).txt  <-- 本題前に見せる前置きテキスト
│   └──  （リンクがある場合）📄 URL-00#__(ドメイン名).txt   <-- 1リンクにつき1ファイル生成される
│
├── 📁 00#-(研究タイトル)
│   │
〜〜省略〜〜
```

### 3. モードの切り替え
画面上部のタブから用途に合わせて切り替えます。
* **[準備用]**: 発表データのアップロードや構成確認を行います。
* **[配信用]**: 配信画面に取り込むためのプレビュー画面を表示します。
* **[設定]**: 動作や音調の調整を行います。

### 3. CSVファイルの読み込みと操作
1. 「準備用」タブを開き、**[CSVを読み込む]** から対象のCSVファイルをアップロードします。
2. 読み込みが完了すると、左側メニューに操作ボタンが生成されます。
3. 項目を選択すると、画面上に **ファイル内容** および **生成ファイル構成** がプレビュー表示されます。
