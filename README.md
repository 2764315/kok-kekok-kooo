# 発表配信ツール ｺｯｹｺｯｺ-!!! 🐓

配信での発表資料提示や、Googleフォームを用いた発表受付からの準備作業をスムーズに行うためのWebツールです。  
Googleフォームの回答データから発表用フォルダや案内資料（README.txt）を一発生成し、OBS Studioなどの配信ソフトに取り込んでそのまま本番進行できます。

👉 **[Web版ツールを開く](https://2764315.github.io/kok-kekok-kooo/)**

---

## 🔄 全体の流れ

1. **Googleフォーム**から回答データ（CSV）をダウンロード
2. **【準備用】** ツールで回答CSVを読み込み、発表用フォルダ・案内資料を一括生成
3. **ローカル環境**で生成されたフォルダに動画・PDF等の実ファイルを配置
4. **【配信用】** ツールでフォルダをまとめて読み込み
5. **OBS Studio等**で画面をキャプチャーし、タイマーや赤ペン機能を使って本番進行

---

## 📖 詳しい使い方手順

### STEP 1：Googleフォームから回答CSVをダウンロードする

1. 発表を受け付けた **Google フォーム** の管理画面を開きます。
2. 画面上部の **「回答」** タブをクリックします。
3. 画面右上の **緑色の「Google スプレッドシートで表示」アイコン** をクリックするか、縦3点リーダーアイコン（⋮）から **「回答をダウンロード (.csv)」** を選択します。
   * *スプレッドシートを開いた場合*: メニューの `ファイル` ＞ `ダウンロード` ＞ `カンマ区切り値 (.csv)` を選択してパソコンに保存してください。

---

### STEP 2：ツール【準備用】でフォルダ・案内テキストを自動生成する

1. **[発表配信ツール ｺｯｹｺｯｺ-!!!](https://2764315.github.io/kok-kekok-kooo/)** にアクセスします。
2. 左側アクティビティバーの一番上にある **「準備用」アイコン（フォルダマーク）** を選択します。
3. 画面上の **「CSVファイルを読み込む」** ボタンを押し、STEP 1でダウンロードしたCSVファイルを選択します。
4. **表示項目の調整**:
   * 配信で表示したくない項目（連絡先など）を非表示にできます。
   * 不要な回答データやファイルは削除ボタンで除外できます。
5. **ZIPダウンロード**:
   * 画面下部の **「ZIPで一括ダウンロード」** をクリックします。
   * 各発表者ごとの連番付きフォルダ（`001_(研究タイトル)/` 等）と、URLや概要が記載された `README.txt` が入ったZIPファイルがダウンロードされるので、解凍してください。

---

### STEP 3：ツール【配信用】でフォルダを読み込む

1. ツール画面の左側アクティビティバーから **「配信用」アイコン（モニターマーク）** を選択します。
2. サイドバーにある **「フォルダを読み込む」** ボタンをクリックします。
3. STEP 2でダウンロードしたZIPファイルを解凍し、 **「すべての発表フォルダが入っている親フォルダ」** (「ｺｯｹｺｯｺｰ!!!_月日時分秒」フォルダ)を選択して読み込みます。
5. サイドバーに発表順のリストが表示され、クリックすると中央のプレビューエリアに各種ファイルが表示されます。

---

### STEP 4：ツール【配信用】で内容を確認する

1. STEP 3でプレビューし、前置きテキストやURLの内容を確認してください。
   * 【重要】ダウンロード用URLが含まれている：ギガファイル便など、ダウンロード用URLがある場合は資料をダウンロードして、URL.txtを削除してください。
   * 【推奨】前置きテキストを内容を変更したい：手動でtxtファイルを編集し、保存してください。
   * 【セーフ】閲覧できないサイトがある：操作やプレビューができないサイトがあります。サイト側の設定によるものなので、新規タブを開いてキャプチャーしてください。
2. 解凍したフォルダの中に、ダウンロードした発表資料を配置します。
   * プレビュー可能なファイル例：
```text
  🖼️ 画像： .jpg, .jpeg, .png, .gif, .webp
  📹️ 動画: .mp4
  🎵 音声: .mp3, .wav, .m4a
  📄 ドキュメント: .pdf`, .txt, .html
  URL.txtによる埋め込み表示対応：Google ドキュメント / スプレッドシート / スライド、OneDrive、YouTube など
```
   * 【重要】Officeファイルが表示できない：PowerPoint（.pptx）などのファイルはプレビューできません。ただし、自分のGoogleドライブに保存し、共有リンクをURL.txtとして保存すれば表示できる場合があります。
   * 【重要】実行ファイルが含まれている：ゲームなどの実行データはプレビューできません。
   * 【推奨】よくわからないが、プレビューできない：自分のGoogleドライブに保存し、共有リンクをURL.txtとして保存すれば表示できる場合があります。それでもできない場合、できないとされています。

### STEP 5：OBSでの配信・本番発表の進行

1. **OBSキャプチャー設定**:
   * OBS Studioを起動し、ソースに **「ウィンドウキャプチャ」** を追加します。
   * ブラウザのプレビュー表示エリアをキャプチャー対象に設定します。
2. **本番の操作**:
   * **発表の切り替え**: 左サイドバーのリスト項目をクリック（または前へ/次へボタン）するだけで、資料画面とタイマーが自動でリセット・切り替わります。
   * **メディア再生・音量調節**: 動画・音声を再生中、音量スライダーで **最大200%まで音量増幅** が可能です。再生終了時は自動的に再生ボタン状態に戻ります。
   * **赤ペン書き込み**: 画面上の 「赤ペン」 ボタンを押すと、スライドや資料の上にリアルタイムで図や注釈を書き込めます。
   * **クロマキー切り替え**: 「クロマキー」 ボタンを押すと画面背景が鮮やかなグリーンバック（`#00FF00`）に切り替わり、OBS側で人物と合成しやすくなります。

## ⚙️ 初期設定（左下 歯車アイコン）

画面左下の **「設定」ボタン** から各種デフォルト挙動を細かく変更できます。

| タブ | 設定項目 | 内容 |
| :--- | :--- | :--- |
| **フォルダ生成** | 連番の付与 | 出力フォルダ名への (001, 002...) の自動付与 |
| | 見出しスタイル | READMEテキストの見出し装飾（【見出し】 / # 見出し / ―― 見出し ―― / なし） |
| | URL伏せ字ドメイン | リンク誤クリック防止用テキストへのドメイン名付与 |
| **データプレビュー** | README表示サイズ | プレビュー枠の指定サイズ固定（幅・高さ）、文字サイズ、背景色、フォント種類 |
| | アラーム設定 | 指定分数が経過した際に鳴るアラーム時間と音量設定 |
| | **アラーム音選択** | アヒル / カッコウ / ケッカハッピョー / キジバト / **ニワトリ** / オオルリ |

## 🛠️ 対応ファイル・Webサービス

* **画像**: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`
* **動画**: `.mp4`
* **音声**: `.mp3`, `.wav`, `.m4a`
* **ドキュメント**: `.pdf`, `.txt`, `.html`
* **Web埋め込み**: Google ドキュメント / スプレッドシート / スライド、OneDrive、YouTube 動画、Google ドライブ共有リンク
