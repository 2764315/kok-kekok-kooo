# 発表配信ツール ｺｯｹｺｯｺ-!!! 🐓

Googleフォームの回答データから発表用フォルダや案内資料（`README.txt`）を自動生成し、OBS Studioなどの配信ソフトでそのまま発表・進行できるWebツールです。

👉 **[Web版ツールを開く](https://2764315.github.io/kok-kekok-kooo/)**

---

## 🔄 全体の流れ

1. **Googleフォーム**から回答データ（CSV）をダウンロード
2. **【準備用】タブ**でCSVを読み込み、発表用フォルダ・案内資料を自動生成（ZIP保存）
3. **【配信用】タブ**で解凍したフォルダを読み込み
4. 画面上でプレビューを確認しながら、実ファイル（動画・PDF等）を配置・整理
5. **OBS Studio等**で画面をキャプチャーし、タイマーや赤ペン機能を使って本番進行

---

## 📖 使い方手順

### STEP 1：Googleフォームから回答CSVをダウンロード
1. Google フォーム管理画面の **「回答」** タブを開きます。
2. 画面右上の **「Google スプレッドシートで表示」** または縦3点リーダー（⋮）の **「回答をダウンロード (.csv)」** を選択します。
   * *スプレッドシートの場合*: `ファイル` ＞ `ダウンロード` ＞ `カンマ区切り値 (.csv)` で保存してください。

---

### STEP 2：【準備用】フォルダ・案内テキストを自動生成
1. **[発表配信ツール]** にアクセスし、左メニューの一番上にある **「準備用」アイコン** を選びます。
2. **「CSVファイルを読み込む」** ボタンからダウンロードしたCSVを選択します。
3. **表示項目の調整**: 不要な項目（連絡先など）や回答データの除外・並び替えを行います。
4. **ZIPダウンロード**: 画面下の **「ZIPで一括ダウンロード」** を押し、ダウンロードされたZIPファイルを解凍します。

---

### STEP 3：【配信用】フォルダを読み込む
1. 左メニューから **「配信用」アイコン** を選びます。
2. **「フォルダを読み込む」** を押し、STEP 2で解凍した親フォルダ（`ｺｯｹｺｯｺｰ!!!_日時` フォルダ）を選択します。
3. 左サイドバーに発表順リストが表示され、選択すると中央にプレビューが表示されます。

---

### STEP 4：プレビュー確認と資料の整理
1. **内容の確認・編集**:
   * **ギガファイル便などのURL**: リンク先の資料をダウンロードし、不要になった `URL.txt` は削除します。
   * **テキストの修正**: 必要に応じて `txt` ファイルを直接編集・保存します。
   * **外部サイト**: 一部サイトはセキュリティ制限で直接プレビューできないため、新規タブで開いてキャプチャーしてください。
2. **発表資料（実ファイル）の配置**:
   * ダウンロードした発表資料を、該当する各フォルダ内に配置します。

> **💡 対応ファイル・制限事項**
> * **プレビュー可能**: 画像（`.jpg`, `.png`, `.gif`, `.webp`）、動画（`.mp4`）、音声（`.mp3`, `.wav`, `.m4a`）、ドキュメント（`.pdf`, `.txt`, `.html`）
> * **埋め込み対応**: Google ドキュメント / スプレッドシート / スライド、OneDrive、YouTube、Googleドライブ共有リンク（※`URL.txt` 内にリンクを記載）
> * **Office / 実行ファイル**: PowerPoint（`.pptx`）やゲーム等の実行ファイルは直接表示できません。Googleドライブ等に保存し、共有リンクを `.txt` で保存してプレビューしてください。

🕺整理したら、STEP 3に戻って確認してみてください

---

### STEP 5：OBSでの配信・本番進行
1. **OBS設定**: ソースに **「ウィンドウキャプチャ」** を追加し、本ツールのプレビュー画面を取り込みます。
2. **本番の操作**:
   * **発表切替**: リスト選択（または前後ボタン）で画面とタイマーが自動リセット・切り替わります。
   * **音量調整**: 動画・音声は **最大200%まで音量増幅** 可能。再生終了で自動的に停止状態に戻ります。
   * **演出機能**: 「赤ペン」での書き込みや、「クロマキー」でのグリーンバック（`#00FF00`）切り替えが可能です。

## ⚙️ 初期設定（歯車アイコン）

| タブ | 設定項目 | 内容 |
| :--- | :--- | :--- |
| **フォルダ生成** | 連番付与 | フォルダ名への (001, 002...) 自動付与 |
| | 見出しスタイル | READMEの装飾変更（【見出し】 / # 見出し / ―― 見出し ―― / なし） |
| | URL伏せ字ドメイン | 誤クリック防止用テキストへのドメイン名付与 |
| **データプレビュー** | README表示 | 画面サイズ固定（幅・高さ）、文字サイズ、背景色、フォント変更 |
| | アラーム | 経過時間アラーム（分）、音量、音色選択 |

---

## 🛠️ 対応ファイル・Webサービス

* **画像**: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`
* **動画**: `.mp4` / **音声**: `.mp3`, `.wav`, `.m4a`
* **ドキュメント**: `.pdf`, `.txt`, `.html`
* **Web埋め込み**: Google（ドキュメント / スプレッドシート / スライド / ドライブ）、OneDrive、YouTube

## ❓ こんなときは？（トラブルシューティング）

### 🚨 表示・エラーについて
* **「Officeファイルはプレビューできません」と出る** 👉 PDF/画像に変換して配置するか、Googleドライブに保存して共有リンクを `.txt` に記載してください。
* **「注意案内：ダウンロード用URL〜」と出る** 👉 記載URLから実ファイルをPCにダウンロードし、`.txt` と差し替えて再読み込みしてください。
* **CSVが文字化けする** 👉 CSVの文字コードを **UTF-8（BOM付き推奨）** で保存し直してください。

### 🔊 音声・動画について
* **音が出ない / アラームが鳴らない** 👉 ブラウザの自動再生制限の可能性があるため、画面内を一度クリックしてください。
* **音量をもっと大きくしたい** 👉 音量スライダーを一番右まで動かすと **最大200%（2倍）** まで増幅できます。

### 🎥 動作・OBS連携について
* **「フォルダを読み込む」が動かない** 👉 PC版 **Google Chrome** または **Microsoft Edge** の最新版をご利用ください。
* **OBSで画面が映らない** 👉 OBSの「ブラウザ」ソースではなく、通常のブラウザでツールを開き **「ウィンドウキャプチャ」** で取り込んでください。
